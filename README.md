# Saleha Owesh Nikah

Create a premium, elegant and minimal interactive Nikah wedding invitation website for:

SALEHA ❤️ OWESH

IMPORTANT:

Use the uploaded/reference wedding invitation card as the PRIMARY visual and content reference.

The website should feel like the physical invitation card has been transformed into a beautiful digital interactive invitation.

DO NOT create a generic wedding website.

DO NOT add unnecessary sections.

━━━━━━━━━━━━━━━━━━━━

OVERALL DESIGN

━━━━━━━━━━━━━━━━━━━━

Match the reference invitation card's aesthetic:

- Cream / ivory background

- Dark teal / deep green typography

- Subtle gold accents

- Elegant floral decorations

- Traditional roses

- Hanging Islamic lanterns

- Delicate floral patterns

- Traditional ornamental dividers

- Elegant calligraphy-style headings

- Sophisticated Islamic wedding aesthetic

Keep the design clean, premium and spacious.

Do NOT make it overly colourful.

Do NOT use excessive hearts, stickers or random decorations.

OPENING SCREEN

━━━━━━━━━━━━━━━━━━━━

Create a beautiful full-screen opening animation.

Use a cream background with subtle floral patterns.

Display:

“In the name of ‘ALLAH’

the most beneficent and the most merciful”

Then reveal:

“SALEHA”

“Weds”

“OWESH”

“Open Invitation ✨”

- Reveal the floral and lantern decorations gradually.

NO music.

NO sound.

NO audio controls.
